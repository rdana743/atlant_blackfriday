# Атлант — Чёрная пятница 11.11

Лидген-лендинг стоматологии «Атлант» (Тюмень): скидка на протезирование зубов к Чёрной пятнице.

`index.html` — HTML, CSS и JS без зависимостей и сборки. Шрифты (Manrope, Unbounded, лицензия OFL) лежат локально в `fonts/`.

Разметка целей и событий — в [EVENTS.md](EVENTS.md).

## Запуск локально

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000

## Настройки

Блок `window.LANDING` в начале `index.html`:

| Параметр | Что это |
|---|---|
| `discount` | Скидка, %. Цены, калькулятор и тексты пересчитываются автоматически |
| `deadline` | Конец акции (время Тюмени, UTC+5) |
| `slotsTotal`, `slotsLeft` | Всего мест по акции и сколько осталось |
| `phone`, `phoneView` | Телефон клиники |
| `endpoint` | URL вебхука для заявок (POST, JSON). Пусто — заявки только в консоль |
| `metrikaId` | Счётчик Яндекс Метрики |
| `vkPixelId` | Пиксель VK Рекламы (top.mail.ru) |
| `privacyUrl` | Ссылка на согласие на обработку персональных данных |

## Заявки

Каждая форма отправляет на `endpoint` JSON: телефон, источник формы (квиз, прайс, врач, калькулятор, exit-intent и т.д.), детали (ответы квиза, выбранная позиция), скидку, страницу, referrer и UTM-метки (`utm_*`, `yclid`, `gclid`).

## Перед запуском

- Фото врачей и кейсов сейчас подгружаются с atlanttumen.ru — лучше сохранить их в `img/` и поменять пути в массивах `docs` и `works`.
- Подключить `endpoint` к CRM / Telegram и указать `metrikaId`.
- Обновлять `slotsLeft` реальными цифрами.
